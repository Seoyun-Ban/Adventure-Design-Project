# 역사 한걸음

> 걸어서 만나는 우리 역사 — 역사 유적지를 직접 방문하고 학습하면 지도에 **발자국**이 남는 위치 기반 역사 학습 앱

충남대학교 어드벤처디자인 팀 프로젝트 프로토타입입니다.

- 🔗 데모: https://adventure-design-project.vercel.app/
- 📄 기획서: `docs/` 참고

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 지도 | 남한 지도 위에 실제 내 위치(브라우저 위치 기능, 위치는 저장하지 않음), 발자국(학습 완료), 학습 가능한 장소 표시. 장소 500m 안에 직접 가면 해금되고 "근처에 ○○이 있어요" 알림. 드래그·핀치·휠로 이동/확대, 현재 위치로 이동. 지도 아래 버튼은 '발자국'·'학습 가능 지역' 켜고 끄기와 '퀴즈' 세 개 |
| 역사 학습 | 장소별 3D 배경, 쉬움/보통/어려움 3단계 학습 글, 관심 장소 등록 |
| 학습 영상 장면 | 장소 배경 그림(천천히 확대) 위에서 역사 인물과 내 캐릭터(등록한 얼굴, 입은 옷 그림)가 대화. 화면을 누를 때마다 다음 대사, 말풍선 글자가 한 글자씩 나타나는 효과, 일러스트 캐릭터, 말할 때 움직임, 전체 화면 |
| 퀴즈 | 학습 단계와 같은 난이도. 쉬움은 O/X·보기 3개(틀리면 힌트를 보고 한 번 더), 보통은 보기 4개, 어려움은 연도·인물 연결과 '왜 그랬을까' 문제 중심. AI(Claude API) 출제 또는 기기 안 자동 생성으로 매번 다른 문제. 맞힌 문제마다 경험치(쉬움 10·보통 20·어려움 30), 경험치 100마다 레벨 1. 지도의 '퀴즈'에서 학습한 장소를 골라 풀기 |
| 이야기책 | 주제별 책 모양 책장, 전체 권 수 대비 발견한 책, 책마다 읽은 이야기 진행률, 키워드 검색 |
| 아바타 | 첫 이용 시 닉네임·성별·머리 모양·얼굴 등록, 일러스트 캐릭터, 학습으로 역사 아이템 수집, 머리·손 아이템은 캐릭터에 직접 입히고, 옷은 옷을 입은 캐릭터 그림으로 바꿔 보여줌(짧은 머리·땋은 머리, 나머지 머리 모양은 아직 배지) |
| 아이템 획득 | 처음 학습을 마치면 그 장소의 아이템 카드가 빙글 돌며 나타남(움직임 줄이기 설정에서는 살며시), "○○을 얻었어요!"·설명·[바로 입어보기]/[나중에]. 아이템 이름과 설명은 장소의 인물을 떠올리게 하는 말로 (예: 이순신을 기리는 투구) |
| 보스전(협동) | 아바타 탭 '함께하기'의 큰 '보스전 (협동)' 버튼. 한 기기에서 2~4명이 이름을 적고 번갈아 문제를 풀어 '까먹기 괴물'을 물리침. 사람이 늘면 괴물 체력도 늘고, 차례마다 난이도(쉬움/보통/어려움)를 골라 어려울수록 피해가 큼. 연속 정답은 콤보, 틀리거나 문제당 15초 제한 시간이 다 되면 괴물이 반격해 팀 하트(3개)가 하나 줄고 화면이 흔들림(움직임 줄이기 설정에서는 약하게), 하트가 0이면 패배. 10라운드 안에 못 쓰러뜨리면 괴물이 도망감. 하트 수·제한 시간은 `boss.ts`에서 바꿈. 학습을 마친 장소가 3곳 이상이어야 열리고(기준은 `data/battle.ts`의 `TOGETHER_MIN_PLACES`), 모자라면 버튼이 잠긴 모습으로 '장소 3곳을 학습하면 열려요 (지금 2/3)'를 보여주며 누르면 안내가 뜸. 문제는 이 기기에서 학습을 마친 장소의 퀴즈에서만 나오고, 고른 난이도의 문제를 한 판 안에서 되도록 반복하지 않으며 바닥나면 다시 섞어 냄(`createQuestionDeck`). 이기면 함께한 이름이 모두 나오는 축하 화면(순위 없음), 경험치와 배지 '함께 물리친 괴물'. 괴물 이름·모습은 `src/data/boss.ts` 한 곳에서 바꿈 |
| 친구와 대결 | 아바타 탭 '함께하기'의 '대결 (경쟁)' 버튼으로 시작. 내 차례마다 난이도(쉬움/보통/어려움)를 고르고(보스전과 같은 `LevelPicker`), 문제를 맞히면 공격/방어 선택, 턴제. 어려울수록 공격 피해가 크고 방어도 더 많이 막음(수치는 `src/data/battle.ts`). 전투력 = 아이템 능력치 + 레벨 보너스. 승패 모션, 다시 도전, 대결 기록(승률·최근 5판)은 경쟁 화면에 표시. 학습을 마친 장소가 3곳 이상이어야 열리고(기준은 `data/battle.ts`의 `TOGETHER_MIN_PLACES`), 모자라면 버튼이 잠긴 모습으로 '장소 3곳을 학습하면 열려요 (지금 2/3)'를 보여주며 누르면 안내가 뜸. 문제는 이 기기에서 학습을 마친 장소의 퀴즈에서만 나오고, 고른 난이도의 문제를 한 판 안에서 되도록 반복하지 않으며 바닥나면 다시 섞어 냄(`createQuestionDeck`) |
| 도전장 링크 | 서버 없이 내 아바타(닉네임·외형·아이템·레벨, 얼굴 사진 제외)를 링크에 담아 친구에게 공유 → 받은 친구가 그 아바타와 대결, 답장 도전장 |
| 내 정보 | 남긴 발자국·읽은 이야기·완료한 퀴즈, 획득한 배지, 관심 장소, 학습 아카이브, 도움말, 닉네임 바꾸기. 오른쪽 위 톱니바퀴로 설정 |
| 설정 | 기본 학습 단계, 푸시 알림, 개인정보 고치기(닉네임·성별·머리 모양·얼굴 사진), 계정 관리(이메일·비밀번호 바꾸기, 회원 탈퇴 — 화면과 흐름만), 로그인/로그아웃, 처음부터 다시 시작하기 |
| 도움말 | 내 정보에서 앱 사용법과 자주 묻는 질문을 초등학생 눈높이로 안내, 문의하기·내 문의 내역 (기기에만 저장, 화면과 흐름만) |
| 로그인·회원가입 | 간편 로그인(공식 아이콘), 이메일 로그인, 회원가입(약관 동의, 태어난 해·달로 만 14세 미만이면 보호자 허락 단계 — 간편 로그인 첫 이용도 동일), 비밀번호 찾기 — 화면과 흐름만, 실제 인증 없음 |
| 앱 소개 안내 | 아바타를 만들고 지도에 처음 들어오면 한 번: 화면을 어둡게 하고 설명할 곳만 밝게 비추며 내 아바타가 말풍선으로 7단계 안내(지도·장소 표시·지도 아래 버튼·이야기책·아바타·내 정보), 탭 자동 이동, 건너뛰기. 끝나면 위치 설명 화면. 도움말 '앱 소개 다시 보기' |
| 먼저 둘러보기 | 회원가입 없이 이용, 기록은 기기(localStorage)에 저장, 로그인하면 이어서 사용 |

기획서 항목별 구현 현황은 [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md)에 정리했습니다.

## 실행 방법

[Node.js](https://nodejs.org/) 20 이상이 필요합니다.

```bash
npm install      # 처음 한 번만
npm run dev      # 개발 서버 실행 → 터미널에 나오는 주소(http://localhost:5173)를 브라우저로 열기
npm run build    # 배포용 빌드 (타입 검사 포함)
npm run format   # 코드 정렬 (Prettier)
npm run images   # 캐릭터 그림 용량 줄이기 (art/characters → public/images/characters)
```

컴퓨터 브라우저(마우스)에서는 휴대폰 모양 틀 안에 앱이 보이고, 창이 작으면 틀이 통째로 줄어들어 항상 화면 안에 다 들어옵니다. 휴대폰·태블릿은 화면을 꽉 채우고, 태블릿처럼 넓은 화면에서는 내용을 가운데에 모아 보여줍니다.
브라우저 개발자 도구(F12)에서 모바일 화면 모드(Ctrl+Shift+M)로 보면 실제 폰 화면처럼 볼 수 있습니다.

## 기술 스택

React 19 · TypeScript · Vite · Tailwind CSS v4 · three.js (3D 배경) · @svg-maps/south-korea (남한 지도) · Vercel Functions + Claude API (AI 퀴즈, 선택)

초기 화면 디자인은 Figma Make로 생성한 뒤 코드 구조를 정리했습니다.

## AI 퀴즈 켜기 (선택)

`api/quiz.ts`는 Vercel 서버리스 함수입니다. Vercel에 배포한 뒤 프로젝트 설정 → Environment Variables에 `ANTHROPIC_API_KEY`를 넣으면 AI가 학습 글을 읽고 퀴즈를 만듭니다 (`ANTHROPIC_MODEL`로 모델 변경 가능). 키는 서버에만 있고 브라우저에는 노출되지 않습니다. 키가 없거나 로컬 실행(`npm run dev`)에서는 자동으로 기기 안 생성 퀴즈를 씁니다. API 사용량만큼 비용이 발생합니다.

## 캐릭터 그림 출처

학습 영상 장면의 캐릭터 그림(`public/images/characters/`, 원본은 `art/characters/`)은 팀에서 **Canva AI**로 생성했습니다. 그림이 아직 없는 인물은 코드로 그린 SVG 캐릭터로 보여줍니다.

## 프로토타입 범위

실제 GPS, 로그인 서버, 얼굴 인식, AI 이미지 생성은 연결하지 않고 화면 흐름과 사용 경험을 보여주는 데 집중했습니다.

- 장소 방문 여부는 `data/places.ts`의 `status`로 가정합니다 (`available` = 방문함, `locked` = 미방문).
- 처음 실행하면 시연을 위해 수원화성이 학습 완료, 경복궁·불국사가 열린(아직 학습 전) 상태로 시작하고 아바타는 아무것도 입지 않은 기본 모습입니다. 설정 화면(내 정보 오른쪽 위 톱니바퀴)의 '처음부터 다시 시작하기'로 학습 기록과 아바타를 처음 상태로 돌리고 로그인 화면부터 다시 시작할 수 있습니다.
- 등록한 얼굴 사진은 서버로 보내지 않고 기기에만 저장합니다.

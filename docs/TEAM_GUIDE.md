# 개발 가이드

## 1. 처음 받아서 실행하기

1. [Node.js](https://nodejs.org/) (LTS 버전), [Git](https://git-scm.com/), [VS Code](https://code.visualstudio.com/) 설치
2. 저장소 받기
   ```bash
   git clone <저장소 주소>
   cd <저장소 폴더>
   npm install
   npm run dev
   ```
3. 터미널에 나온 `http://localhost:5173` 을 브라우저에서 열기 (F12 → Ctrl+Shift+M 으로 모바일 화면)

## 2. 작업 규칙

- **작업 시작 전에 꼭 `git pull`** 해서 최신 코드 받기
- 기능 하나 끝날 때마다 커밋, 커밋 메시지는 한글로 무엇을 했는지 짧게
  예: `온보딩 화면 추가`, `불국사 사진 추가`
- 올리기 전에 `npm run build` 가 에러 없이 끝나는지 확인

```bash
git pull
# ... 작업 ...
git add .
git commit -m "작업 내용"
git push
```

### 캐릭터 그림 추가하기

학습 영상 장면의 역사 인물 그림은 아래 이름으로 넣으면 자동으로 SVG 캐릭터 대신 그림이 나옵니다. (`src/data/figures.ts`의 `image`)

| 인물 | 파일 이름 | 상태 |
| --- | --- | --- |
| 태조 이성계 | `taejo.png` | ✅ |
| 정조 | `jeongjo.png` | ✅ |
| 이순신 | `yisunsin.png` | ✅ |
| 김대성 | `kimdaeseong.png` | ✅ |
| 김구 | `kimgu.png` | ✅ |
| 유관순 | `yugwansun.png` | ✅ |
| 내 캐릭터 남 (짧은 머리/상투) | `me-boy-short.png`, `me-boy-sangtu.png` | ✅ |
| 내 캐릭터 여 (땋은 머리/단발/장발) | `me-girl-braid.png`, `me-girl-bob.png`, `me-girl-long.png` | ✅ |

1. 배경이 **투명한** PNG로 만든다 (전신, 정면, 기존 그림과 비슷한 비율)
2. 원본을 `art/characters/` 폴더에 넣는다
3. 터미널에서 `npm run images` → 여백을 자르고 용량을 줄인 그림이 `public/images/characters/`에 생긴다 (약 1MB → 100KB)
4. `npm run dev`로 확인 후 커밋 (원본과 줄인 그림 둘 다)

내 캐릭터 그림을 바꾸거나 머리 모양을 추가하면 `src/data/avatar.ts`의 `characterStyles`에서 그림 경로, 얼굴 사진 위치(`face`), 아이템 배지 자리(`slots`), 머리·손 아이템 자리(`mounts`)를 그림에 맞게 고쳐야 합니다. 머리 모양을 추가할 때는 `src/types.ts`의 `CharacterStyleId`에도 이름을 더합니다. 성별마다 맨 앞에 적은 머리 모양이 기본값이에요. 얼굴 사진은 윤곽대로 잘라 붙이므로 `face` 값을 같이 쓰고, 어색하면 같은 파일의 `CUTOUT_FIT`(공통)이나 그림별 `cutout`(옮김·배율)을 조정하세요. 얼굴은 기본이 사진 그대로이며 색감 보정 강도는 `src/lib/faceCrop.ts`의 `PHOTO_TONE`, 만화풍(설정에서 선택) 강도는 `CARTOON_STYLE`에서 바꿉니다.

### 아이템 그림 넣기

머리·손 아이템은 캐릭터에 직접 입혀집니다. 옷은 **옷을 입은 캐릭터 그림**으로 통째로 바뀌고, 그 머리 모양의 옷 그림이 아직 없으면 캐릭터 옆에 원형 배지로 보입니다.

| 아이템 | 파일 | 상태 |
| --- | --- | --- |
| 선비 갓, 장군 투구 (머리) | `item-gat.png`, `item-helmet.png` | ✅ |
| 정조 활, 화랑 검, 독립선언서 (손) | `item-bow.png`, `item-sword.png`, `item-declaration.png` | ✅ |
| 태극기 (손) | 코드로 그림 (`components/ItemArtView.tsx`, 국기 규격대로 `Taegukgi.tsx`) | ✅ |
| 관복, 화랑 예복, 갑옷 (몸) | 옷을 입은 캐릭터 그림 `me-{머리모양}-{옷}.png` (옷: robe·hwarang·armor) | 머리 모양 5종 모두 ✅ (15장) |

옷 그림 넣는 법: 기본 캐릭터와 **같은 자세·같은 크기**로 옷만 바꾼 투명 PNG를 `art/characters/me-{머리모양}-{옷}.png`로 넣고 `npm run images`만 실행하면 앱이 자동으로 그 그림을 써요 (모자·손 위치가 어긋나면 `src/data/avatar.ts`의 `OUTFIT_FIT`에서 맞춰요).

새 아이템 그림 넣는 법:
1. 아이템만 그린 투명 PNG를 `art/characters/item-이름.png`로 넣고 `npm run images`
2. `src/data/avatar.ts`의 그 아이템에 `art`를 적는다
   - `anchor`: 아이템 그림에서 캐릭터에 맞출 점 (모자: 이마에 닿는 아래 테두리, 손 아이템: 쥐는 부분)
   - 모자는 `width`(머리 너비의 몇 배), 손 아이템은 `height`(캐릭터 키의 몇 %)
   - 모자 아래쪽(끈·목가리개)이 얼굴을 가리면 `split`(나눌 높이 %)과 `below`('behind' 뒤에 그리기 / 'hide' 빼기)
   - 그림 옆에 세로 이름표를 붙이려면 `tag` (예: 독립선언서). 아이템 목록·상세 창·획득 카드에서만 보이고 손에 들 때는 작아서 빠져요
3. 캐릭터 그림마다 머리·손 자리는 `characterStyles`의 `mounts`에 있다 (그림을 바꾸면 이 값도 다시 맞춘다)

⚠️ 태극기가 들어간 그림은 꼭 크게 확대해서 확인하세요. AI 그림은 괘 배치나 태극 소용돌이 방향이 틀리는 경우가 많습니다. (`item-flag.png`는 태극 방향이 뒤집혀 있어서 쓰지 않고 코드로 그렸습니다. 원본은 `art/unused/`에 보관 — 이 폴더는 `npm run images`가 처리하지 않아요.)

### 영상 장면 목소리 (현재 꺼 둠)

녹음 파일을 넣으면 재생할 수 있는 구조를 갖춰 두었고, 현재는 꺼 둔 상태입니다. 대사는 말풍선 글자가 한 글자씩 나타나는 효과로만 보여주고, 소리 버튼도 숨겨져 있어요.

- 켜고 끄는 값: `src/lib/speech.ts` 위쪽의 `SCENE_VOICE_ENABLED` (지금은 `false`)
- 녹음 파일 위치: `public/audio/장소id/줄번호.mp3` (줄번호는 1부터, `src/data/figures.ts`의 대사 순서). 내 캐릭터 대사는 `줄번호-boy.mp3`, `줄번호-girl.mp3`
- 파일 목록(`src/data/generated/audioFiles.ts`)은 `npm run dev`나 `npm run build`를 할 때 자동으로 만들어집니다. 앱은 이 목록에 있는 파일만 재생해요.
- 녹음 파일이 없는 줄은 기기의 한국어 목소리로 읽습니다.

### 내 얼굴 다듬기 (사진 그대로)

학습 영상 장면의 내 얼굴이 어색하면 `src/data/faceTuning.ts`의 숫자만 바꿉니다 (색 보정 강도·밝기 한계, 가장자리 번짐, 이마·턱 자르기, 얼굴 크기).
- `tone`·`edge`·`crop`은 얼굴을 **등록할 때** 만들어지므로, 바꾼 뒤 얼굴을 다시 등록해야 보입니다.
- `fit`(얼굴 크기·세로 누르기)은 장면에 붙일 때 적용되어 저장된 얼굴에도 바로 적용됩니다.

### 처음 시작 체험(튜토리얼) 문구 고치기

온보딩을 마치면 경복궁 이야기를 직접 해 보는 체험이 시작됩니다. **말풍선 문구는 모두 `src/data/tutorial.ts`의 `BEATS`**에 있습니다. `title`(제목)·`body`(내용)만 고치면 됩니다 (`
`은 줄 바꿈). 숫자가 들어가는 문구(모은 아이템 수, 함께하기 3곳)는 `body`가 함수라서 `${...}` 부분은 그대로 두세요.
- 말풍선은 비춘 곳을 가리지 않는 위·아래에 뜨고, 자리가 모자라면 맨 위·맨 아래의 한 줄 띠가 됩니다. 띠에 쓰는 글은 `strip`(한 줄에 들어가게 짧게, 약 20자 안팎)입니다.
- 각 단계의 `spots`는 밝게 비출 곳, `advance`는 넘어가는 조건(직접 누르기 `tap` / 화면 신호 `signal` / '다음' 버튼 `next`)입니다. 이 부분은 화면 코드와 연결되어 있으니 바꾸기 전에 물어보세요.
- 체험을 잠깐 끄려면 `data/tutorial.ts`의 `TUTORIAL_FINAL`을 `false`로 바꿉니다 (그러면 주소 끝에 `?tutorial`을 붙여 열 때만 체험이 시작됩니다).
- 체험 상태는 `progress.tutorialStep`(1~7, 끝나면 지워짐)에 저장되고, 앱을 닫았다 열면 그 묶음의 처음부터 이어집니다.
- 체험을 다시 해 보려면 설정의 '처음부터 다시 시작하기'를 누르고 온보딩을 마치세요. (도움말의 '앱 소개 다시 보기'는 화면 설명만 다시 보여 주는 별도 기능이고 학습 기록이 쌓이지 않습니다.)

### 낱말 풀이 (밑줄 낱말)

아이들이 다른 뜻으로 오해하거나 어려워하는 낱말은 `src/data/glossary.ts` 한 파일에 모아 둡니다. 낱말을 더하려면 목록에 `{ word: '낱말', hanja: '漢字', meaning: '풀이' }` 한 줄만 추가하면 됩니다 (한자가 없으면 `hanja`는 생략).
- 학습 글·'알고 있었나요?'·'외우기 한 줄'에서 그 낱말이 **처음 나오는 곳에만** 점선 밑줄이 그어지고, 누르면 낱말 바로 아래에 "낱말(한자) - 풀이" 말풍선이 뜹니다 (화면 아래쪽이면 위쪽에, 가장자리면 안쪽으로 밀어 화면 밖으로 안 나감. 바깥을 누르거나 스크롤하거나 Esc로 닫기, 키보드 Tab·Enter 가능).
- 퀴즈는 **문제 글에만** 적용합니다. 보기와 정답 설명은 답을 알려줄 수 있어서 제외입니다. 상상 대화 장면은 누르면 다음 대사로 넘어가서 적용하지 않습니다.
- 낱말 일부에는 밑줄이 그어지지 않습니다 (근정전 안의 '정전', 활시위 안의 '시위' 등). 낱말 앞에 한글이 붙어 있거나, 뒤에 조사가 아닌 한글이 붙어 있으면 다른 낱말로 봅니다 (`src/lib/glossary.ts`). 낱말을 더한 뒤에는 `npm test`로 확인하세요.
- 레벨 규칙: 1→2레벨에 필요한 경험치(`XP_FIRST_LEVEL`=100)와 레벨마다 늘어나는 양(`XP_LEVEL_STEP`=20)은 `src/lib/level.ts` 한 곳에서 고칩니다. 고친 뒤 `npm test`의 레벨 테스트 숫자도 맞춰 주세요.
- 대결 랭킹: 가상 친구들의 처음 승패는 `src/data/battle.ts`의 `LEAGUE_START`에서 고칩니다. 내 대결이 끝날 때마다 가상 친구끼리도 한 판씩 겨루는 수치(레벨당 이길 확률 3%, 35~65% 한계)와 순위 계산은 `src/lib/league.ts`이고 고친 뒤에는 `npm test`로 확인하세요.
- 글에 괄호로 뜻을 붙이지 말고 이 목록에 넣습니다. (퀴즈 보기·정답 설명은 낱말 풀이가 안 붙으므로 괄호 설명을 그대로 둡니다)

### 사진 (학습 글 중간 사진)

학습 글 문단 사이에 사진이 **자동으로 고르게** 들어갑니다 (사람이 위치를 고르지 않음). 사진이 없는 장소는 글만 나옵니다.

**사진 규칙 (꼭 지키기)**
- **공공누리 제1·2유형은 줄여서 사용, 제3·4유형은 원본 그대로만 사용한다.** 제3·4유형은 변경금지라서 사진을 자르거나, 줄이거나, 형식(webp 등)을 바꾸면 안 된다. 사진 위에 글씨나 그림을 겹치지도 않는다. (제3유형은 상업적 이용이 가능하고, 제4유형은 상업적 이용도 금지다. 앱은 비영리 학습용 프로토타입이다)
- **이용 조건을 확인할 수 없는 사진은 넣지 않는다.**
- **출처를 꼭 표시한다.** 앱에서는 사진 아래 작은 글씨로 나오고, 출처 칸이 비어 있으면 사진이 앱에 들어가지 않는다.

**사진 넣는 법**
1. 원본을 `art/photos/장소id/`에 넣는다. 장소 id: gyeongbokgung(경복궁), suwon(수원화성), independence(독립기념관), aunae(아우내 장터), bulguksa(불국사), hansando(한산도). 원본은 용량이 커서 내 컴퓨터에만 두고 저장소에는 올라가지 않는다.
2. `art/photos/sources.csv`에 한 줄을 적는다: `장소,파일 이름,사진 설명,출처,페이지 주소,자르기,변경금지` (엑셀로 열어도 된다). 자르기는 비워 두거나 위·가운데·아래·왼쪽·오른쪽 (목록에서 4:3으로 잘릴 때 어디를 보여줄지, 크게 보기에서는 전체가 나온다). **변경금지 칸**에는 제3·4유형 사진에만 `변경금지`라고 적는다 (자르기 칸에 `변경금지`라고 적어도 같게 읽는다). 표시된 사진은 `npm run images`가 원본 파일을 그대로 복사만 하고(자르기·크기 조절·webp 변환 없음), 화면에서도 원래 비율대로 보여 준다. 출처에는 기관명과 공공누리 유형을 쓰고 페이지 주소를 꼭 적는다 (앱에서 '원본 페이지' 링크로 열린다). 원본이 크면 앱이 느려질 수 있으니 변경금지 사진이 많아지면 용량을 확인한다.
3. `npm run images`를 실행하면 휴대폰에 맞게 줄여 `public/images/photos/장소id/`에 저장하고 목록(`src/data/generated/photos.ts`)이 갱신된다. 줄인 사진·sources.csv·photos.ts를 커밋한다.
4. README '사진 출처'는 이 sources.csv와 같게 유지한다.
5. `npm test`로 사진이 하나도 빠지지 않는지 확인한다 (csv의 사진 수 = 앱 목록 = 화면에 들어가는 사진 수). 배치 규칙(`src/lib/photoLayout.ts`): 사진 순서는 항상 sources.csv에 적힌 순서. 사진 1장은 첫 문단 뒤, 2장 이상은 문단 사이에 고르게, 문단 사이 자리가 모자라면 남는 사진은 모두 마지막 문단 뒤('잠깐, 기억해 볼까요?' 위)에 둔다. 한 자리에 사진이 2장 이상 모이면 옆으로 밀어 넘기는 묶음(아래 '1/2' 표시, 컴퓨터는 좌우 화살표)으로 보여 준다. 세로 사진(세로가 더 긴 사진)은 자르지 않고 원래 비율 그대로 전체를 보여 주며(높이는 화면의 60%까지, 남는 양옆은 배경색), 묶음 안에 세로·변경금지 사진이 섞이면 모든 칸의 크기를 같게 맞춘다. 사진의 가로·세로 크기는 npm run images가 목록에 적는다.

**공공누리 유형은 사진마다 직접 확인한다**
- 국가유산청 API가 사진마다 주는 이용 조건 코드(`imageNuri`: A/F, B/F, D/F)로는 공공누리 유형을 판단할 수 없다. 같은 D/F인데 어떤 사진은 제1유형이고 어떤 사진은 제4유형이었다. 같은 유산 페이지 안에서도 사진마다 유형이 다르다.
- 그래서 코드로 자동 선택하는 `npm run photos`는 만들지 않는다. 사진마다 국가유산포털 상세 페이지에서 공공누리(OPEN) 표시를 직접 보고 제1·2유형인 것만 쓴다.
- 확인한 사진은 API가 주는 원본(`https://www.khs.go.kr/unisearch/images/...jpg`, https로 받는다)을 `art/photos/장소id/`에 저장하고 위 방법대로 `sources.csv`에 적는다. 출처 칸에는 "국가유산청, 공공누리 제○유형"처럼 확인한 유형을 쓴다.

# 학습 영상 장면 녹음 대본

학습 화면의 영상 장면(역사 인물과 내 캐릭터의 대화)에 쓰는 녹음 대본입니다.
대사 원본은 `src/data/figures.ts`이고, 이 문서는 그 대사를 그대로 옮긴 것입니다.

> 지금은 학습 장면 목소리를 꺼 두었습니다 (`src/lib/speech.ts`의 `SCENE_VOICE_ENABLED = false`). 다시 켜는 법은 `docs/TEAM_GUIDE.md`의 '영상 장면 목소리'를 보세요.

- 녹음 파일이 있으면 앱은 **녹음만 재생**하고, 없는 줄만 기기 목소리로 대신 읽습니다.
- 대사를 고치면 이 문서도 같이 고치고, 그 줄의 '녹음 완료' 칸에 **다시 녹음 필요**라고 적어 주세요.
- '읽는 법' 칸은 숫자를 한글로 풀어 쓴 것입니다. 녹음할 때는 이 칸을 보고 읽으세요. 숫자가 없는 줄은 '대사와 같음'입니다.

## 녹음 파일 넣는 법

1. 위 표의 '저장할 파일' 이름 그대로 mp3로 저장합니다. 폴더가 없으면 `public/audio/장소id/` 폴더를 만드세요.
   - 줄번호는 1부터 셉니다. 내 캐릭터 대사는 `-boy`(남자아이), `-girl`(여자아이)을 붙입니다.
   - 앞뒤 조용한 부분은 짧게 잘라 주세요. 대사가 바로 시작돼야 자연스럽습니다.
2. `npm run dev` 또는 `npm run build`를 실행하면 녹음 파일 목록(`src/data/generated/audioFiles.ts`)이 저절로 바뀝니다. 앱은 이 목록에 있는 파일만 재생합니다.
3. 학습 화면 → 영상 장면에서 '○○과 만나기'를 눌러 들어 봅니다. 주소 뒤에 `?debug`를 붙이고 F12 → 콘솔을 보면 `[목소리] … 녹음 파일 …` 줄로 어떤 파일을 재생했는지 나옵니다.
4. 이 문서의 '녹음 완료' 칸에 ✅를 적고, mp3 파일과 목록 파일(`audioFiles.ts`)을 함께 커밋합니다.
5. 일부 줄만 녹음해도 됩니다. 녹음이 없는 줄은 기기 목소리로 대신 읽습니다.

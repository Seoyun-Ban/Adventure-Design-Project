# 기획서 반영 현황

기획서의 각 항목이 프로토타입에서 어떻게 구현되었는지 정리한 표입니다.
✅ 구현 · 🟡 연출(프로토타입에서는 흉내만 냄) · ⬜ 미구현

## 1. 앱 주요 기능

| 기획 항목 | 상태 | 구현 내용 / 위치 |
| --- | --- | --- |
| 지도: 남한 지도 중심 메인 화면 | ✅ | `MapScreen`, `KoreaMap` (남한 행정구역 SVG) |
| 지도 요소: 발자국 / 학습 가능 장소 / 현재 위치 | ✅ | `MapMarker` |
| 확대·축소 시 오브젝트 크기 조정 | ✅ | 확대 비율에 따라 마커·글자 크기 보정 |
| 지도 조작: 확대/축소, 현재 위치로 이동 | ✅ | 우측 하단 버튼, 드래그·핀치·휠 |
| 발자국 획득: 방문 → 해금 → 학습 → '학습 완료' | ✅ / 🟡 | 방문 여부는 `places.ts`의 `status`로 가정 |
| 발자국 선택 → 두 줄 요약 → 전체 화면 학습 | ✅ | 지도 하단 카드 |
| 위치가 불분명한 사건은 학습한 위치에 발자국 | ✅ | `kind: 'event'` (예: 훈민정음 반포) |
| 이야기책: 주제별 묶음, 해금 시 표시, 진행률 | ✅ | `StoryBookScreen`, `storyBooks.ts` |
| 미해금 내용 '아직 발견하지 않은 이야기' | ✅ | |
| 이야기책 키워드 검색 | ✅ | |
| 학습: 전체 화면 소개 글 + 사진 | ✅ | `LearnScreen`, `contents.ts` |
| 학습: 영상 | ✅ / 🟡 | 장소별 3D 배경에서 역사 인물과 내 캐릭터가 대화, 인물별 음성(브라우저 TTS) + 배경 음악 `HistoryScene` |
| 최초 사용 시 얼굴 등록 → 사진/영상에 반영 | ✅ | 온보딩에서 촬영 → 만화풍 변환 → 학습 영상 장면 속 내 캐릭터 얼굴에만 반영 (기기에만 저장) |
| 학습 단계 쉬움/보통/어려움, 기본 보통 | ✅ | 화면 오른쪽 상단, 설정에서 기본값 변경 |
| 하단 '학습 완료' / '퀴즈 풀어보기' | ✅ | |
| 학습 아카이브: 학습 완료·퀴즈 완료 표시 | ✅ | `ArchiveScreen` (실제 기록 기반) |
| 아카이브 연/월 선택 | ✅ | |
| 퀴즈: 학습 내용 기반, 매번 다른 문제 | ✅ | AI 출제(Vercel + Claude API) 또는 사실 묶음 기반 자동 생성 |
| 퀴즈 난이도 = 학습 글 난이도 | ✅ | 난이도별 퀴즈 3문제씩 (`quizBank.ts`) |
| 메뉴의 복습 퀴즈 (틀린 문제 중심) | ✅ | 틀린 문제 자동 저장 → 우선 출제 → 맞히면 제거 |
| 로그인: 간편(네이버·카카오·구글) / 이메일 | 🟡 | 화면과 흐름만 구현, 실제 인증 없음 |
| 이메일 기억하기 | ✅ | 기기에 저장 |
| 먼저 둘러보기 → 기기 저장 → 로그인 시 계정으로 | ✅ / 🟡 | localStorage 저장, 로그인 시 안내 메시지 |
| 푸시 알림: 근처 장소 도착 시 (500m) | 🟡 | 지도 상단 알림 배너로 연출, 반경 값은 `NEARBY_RADIUS_M` |
| 푸시 알림 ON/OFF, 기본 ON | ✅ | 설정 |
| 아바타: 처음 이용 시 성별/체형 등 외형 설정 | 🟡 | 그림 캐릭터 도입으로 현재는 성별만 선택. 체형·머리 모양별 그림이 추가되면 다시 선택 가능 (`OnboardingScreen`의 `SHOW_DETAILED_LOOK`) |
| 역사 인물의 장비·무기·의복 수집 | ✅ | 장소 학습 완료 시 획득 (`avatar.ts`) |
| 아이템마다 능력치 | ✅ | 공격·방어·지혜, 착용 아이템 합산 전투력 |
| 획득/미획득 아이템 확인 | ✅ | 미획득은 자물쇠 + 획득 방법 안내 |
| 아이템 착용 (옷 입히기) | ✅ / 🟡 | 머리·손·몸 부위별 착용/해제, 능력치 반영. 그림 캐릭터에는 지금 부위별 원형 배지로 표시 (옷 그림이 생기면 `art`로 교체) `CharacterAvatar` |
| 친구와 경쟁: 무작위 문제, 맞히면 공격/방어 선택, 턴제 | ✅ | 상대 공격력은 아이템·레벨 기반 `BattleScreen` |
| 이야기책: 책 모양, 전체 권 수 표시 | ✅ | 책장 UI, ‘발견 / 전체 권’ + 진행 바 |
| 내 정보: 획득한 배지, 관심 장소 | ✅ | 배지 9종 자동 획득, 하트로 관심 장소 등록 |

## 2. 화면 및 요소 배치

| 기획 항목 | 상태 |
| --- | --- |
| 홈: 지도 옵션(발자국 ON/OFF, 학습 가능 지역 ON/OFF) | ✅ |
| 학습 가능 지역 반투명 초록색 영역 | ✅ |
| 메뉴: 왼쪽 상단 (학습 아카이브, 설정, 퀴즈, 복습 퀴즈) | ✅ |
| 하단 바: 지도 / 이야기책 / 아바타 / 내 정보 | ✅ |
| 설정: 기본 학습 단계, 로그아웃(비로그인 시 로그인), 푸시 알림 | ✅ |

## 실제 서비스로 만들 때 필요한 것

GPS 위치 연동, 소셜 로그인과 서버 저장, 전문 일러스트 캐릭터, 성우 음성 또는 고품질 TTS, AI 이미지/영상 생성(얼굴 합성)

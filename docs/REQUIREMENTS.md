# 기획서 반영 현황

기획서의 각 항목이 프로토타입에서 어떻게 구현되었는지 정리한 표입니다.
✅ 구현 · 🟡 연출(프로토타입에서는 흉내만 냄) · ⬜ 미구현 · ❌ 기획 변경으로 제외

## 1. 앱 주요 기능

| 기획 항목 | 상태 | 구현 내용 / 위치 |
| --- | --- | --- |
| 지도: 남한 지도 중심 메인 화면 | ✅ | `MapScreen`, `KoreaMap` (남한 행정구역 SVG) |
| 지도 요소: 발자국 / 학습 가능 장소 / 현재 위치 | ✅ | `MapMarker` |
| 실제 내 위치 표시 (브라우저 위치 기능) | ✅ | 처음 지도에 들어가면 쉬운 설명 화면("정확한 위치는 저장하지 않아요. 방문한 장소만 기억해요") → '위치 켜기'를 누르면 브라우저가 허용 여부를 물음. 앱을 보고 있을 때만 위치를 받고 위치는 저장하지 않음. 거절·못 찾음·https 아님·카카오톡 등 앱 안 브라우저("다른 브라우저로 열어 주세요")·아이폰 '정확한 위치' 꺼짐(켜는 방법 안내) 때도 지도는 그대로 사용 `useLocation`, `LocationIntro`, `LocationNotice` |
| 시연용 위치 바꾸기 (화면에 드러나지 않는 숨김 기능) | ✅ | 지도 제목을 2.5초 안에 5번 누르면 '어디에 있나요?' 창 → 고른 장소(해금 지점이 여러 개면 '경복궁 · 광화문'처럼 지점까지)에 있는 것처럼 해금·알림·사건 발자국 시·도까지 동작. 고른 위치는 저장하지 않음 `LocationPicker`. 처음 시작 상태: 경복궁·수원화성 학습 완료, 불국사 열림, 나머지 잠김 |
| 장소를 실제 위도·경도로 지도에 표시 | ✅ | 장소마다 위도·경도(`places.ts`)를 넣고, 지도 그림(메르카토르 방식) 위 위치로 계산. 시·도 17곳 경계로 맞춘 계산식, 평균 오차 약 2km `lib/geo.ts` |
| 울릉도·독도 표시 | ✅ | 본 지도의 동쪽 섬은 '울릉도'로 표시. 독도는 지도 그림 밖이라 오른쪽 위 삽입 지도에 울릉도와 함께 본 지도와 같은 축척·실제 위치로 표시(약 87km) |
| 확대·축소 시 오브젝트 크기 조정 | ✅ | 확대 비율에 따라 마커·글자 크기 보정 |
| 가까운 장소 표시가 겹치지 않게 | ✅ | 독립기념관·아우내 장터처럼 실제로 몇 km 떨어진 곳은 전국 지도에서 겹쳐 보여서, 화면에서 너무 가까운 표시끼리 살짝 떨어뜨리고 실제 위치에는 작은 점과 점선을 남김. 확대하지 않아도 각각 따로 누를 수 있음 `KoreaMap`의 `spreadMarkers` |
| 지도 조작: 확대/축소, 현재 위치로 이동 | ✅ | 우측 하단 버튼, 드래그·핀치·휠 |
| 발자국 획득: 방문 → 해금 → 학습 → '학습 완료' | ✅ | 실제 위치가 장소의 해금 지점 중 하나라도 반경(기본 500m, 넓은 장소는 따로) 안에 들어오고(경복궁: 광화문·근정전, 수원화성: 행궁·네 성문) 위치 오차가 300m 이하일 때 해금. 방문한 장소 id만 저장(`visitedIds`), 위치는 저장하지 않음 |
| 발자국 선택 → 두 줄 요약 → 전체 화면 학습 | ✅ | 지도 하단 카드 |
| 위치가 불분명한 사건은 학습한 위치에 발자국 | ✅ | `kind: 'event'` (예: 훈민정음 반포). 어디서나 학습 가능. 정확한 위치 대신 학습할 때 있던 시·도만 저장하고 그 시·도 대표 지점에 발자국 (위치를 모르면 서울) `lib/regions.ts` |
| 이야기책: 주제별 묶음, 해금 시 표시, 진행률 | ✅ | 지도에 장소가 있는 책은 전부 잠겨 있어도 책장에 꽂히고(표지 자물쇠 + '○○, ○○에 가면 열려요'), 지도에 장소가 없는 책만 '발견하지 않은 책'으로 숨김. 위쪽 'n / 전체 권'은 책장에 꽂힌 책 수. 잠긴 챕터는 지도 장소가 있으면 "○○에 가면 열려요", 없으면 "새로운 이야기가 곧 찾아와요". 책 화면 위쪽에 '열 수 있는 곳' 장소 목록 `StoryBookScreen`, `storyBooks.ts` |
| 미해금 내용 '아직 발견하지 않은 이야기' | ✅ | |
| 이야기책 키워드 검색 | ✅ | |
| 학습: 전체 화면 소개 글 + 사진 | ✅ | `LearnScreen`, `contents.ts`. 학습 글(쉬움·보통·어려움)·외우기 한 줄은 공인된 자료로 확인한 최종본. 화면 맨 아래 '참고 자료' 칸(확인된 링크만 연결, 없으면 자료 이름만). 자료 목록은 `docs/content-sources.md` |
| 학습: 영상 | ✅ / 🟡 | 인물 대사는 교육용 상상 대화라서 장면 아래와 전체 화면 왼쪽 위에 '역사 인물 상상 대화'라고 표시. 장소별 배경 그림(천천히 확대) 위에서 역사 인물과 내 캐릭터(입은 옷 그림, 등록한 얼굴)가 대화. 화면을 누를 때마다 다음 대사, 끝나면 '다시 보기'. 말풍선 글자가 한 글자씩 빠르게 나타남(나오는 중에 누르면 전체 문장, 움직임 줄이기 설정에서는 바로 전체 문장). 인물은 어른 키, 내 캐릭터는 어린이 키. 전체 화면(지원 안 되는 기기는 화면 덮개 방식) `HistoryScene`<br>**학습 장면 음성은 현재 꺼둠, 글자 효과로 대체 (녹음 파일을 넣으면 재생할 수 있는 구조를 갖춰 둠)** — `lib/speech.ts`의 `SCENE_VOICE_ENABLED` |
| 최초 사용 시 얼굴 등록 → 사진/영상에 반영 | ✅ | 온보딩에서 "카메라로 찍기 / 앨범에서 고르기" 선택 (휴대폰: 앞면 카메라·사진 앨범, 컴퓨터: 웹캠 화면 촬영, 웹캠이 없거나 권한 거절 시 앨범 안내) → 만화풍 변환 → 학습 영상 장면 속 내 캐릭터 얼굴에만 반영 (기기에만 저장) |
| 학습 단계 쉬움/보통/어려움, 기본 보통 | ✅ | 화면 오른쪽 상단, 설정(내 정보 톱니바퀴)에서 기본값 변경 |

| 경험치와 레벨 | ✅ | 맞힌 문제마다 쉬움 10·보통 20·어려움 30 XP(힌트 보고 맞히면 절반), 퀴즈 결과 화면에 얻은 경험치와 레벨 변화 표시. 레벨 = 1 + 경험치÷100, 전투력의 레벨 보너스(레벨 × 60)도 같은 레벨을 씀. 내 정보에 다음 레벨까지 남은 경험치 |

## 2. 화면 및 요소 배치

| 기획 항목 | 상태 |
| --- | --- |
| 홈: 지도 옵션(발자국 ON/OFF, 학습 가능 지역 ON/OFF) | ✅ | 지도 아래 버튼은 '발자국', '학습 가능 지역', '퀴즈' 세 개 |
| 학습 가능 지역 반투명 초록색 영역 | ✅ |
| 메뉴: 왼쪽 상단 (학습 아카이브, 설정, 퀴즈, 복습 퀴즈) | ❌ | **기획 변경: 팀 회의·교수님 피드백으로 사이드 메뉴 없앰.** 퀴즈 → 지도의 '퀴즈' 버튼, 학습 아카이브·도움말 → 내 정보 탭, 설정 → 내 정보 오른쪽 위 톱니바퀴, 복습 퀴즈 → 제외 |
| 처음 시작할 때 앱 소개 안내 | ✅ | 온보딩을 마치고 지도에 처음 들어오면 한 번(위치 설명 화면보다 먼저). 화면을 살짝 어둡게 하고 설명할 곳만 밝게 비추는 스포트라이트 + 내 아바타 말풍선, 이전/다음·진행 점·건너뛰기, 탭 자동 이동. 7단계: 지도 → 장소 표시(회색 자물쇠·초록·발자국) → 지도 아래 버튼 → 이야기책 → 아바타 → 내 정보 → 떠나기. 건너뛰면 다시 자동으로 나오지 않고, 도움말 맨 위 '앱 소개 다시 보기'로 다시 볼 수 있음. 휴대폰·태블릿·컴퓨터(줄어든 틀)에서 비추는 위치 확인, 움직임 줄이기 설정에서는 애니메이션 끔 `AppTour` |
| 도움말 (앱 사용법 7가지 + 자주 묻는 질문 5가지, 누르면 펼쳐지는 방식) | ✅ | 내 정보 탭에서 열기 |
| 도움말: 문의하기 (종류·제목·내용 → 내 문의 내역, 답변 대기 중/답변 완료) | 🟡 | 화면과 흐름만 구현. 문의는 기기에만 저장하고, 운영팀 답변은 시연용 예시 1건. 실제 서비스에서는 서버 저장·관리자 답변 필요 |
| 하단 바: 지도 / 이야기책 / 아바타 / 내 정보 | ✅ |
| 컴퓨터·태블릿 화면에서 보기 | ✅ | 마우스로 쓰는 컴퓨터: 휴대폰 모양 틀(393×852)을 가운데에 두고, 화면 세로가 짧으면 틀을 통째로 비율 그대로 줄여 하단 바까지 항상 보이게 함 (바텀시트·토스트·영상 장면 전체 화면도 틀 기준) `lib/frameScale.ts`. 터치 기기(휴대폰·태블릿)는 가로로 눕혀도 화면을 꽉 채우고, 가로 600px 이상이면 내용을 가운데 600px 너비로 모음 |
| 설정: 기본 학습 단계, 로그아웃(비로그인 시 로그인), 푸시 알림 | ✅ | 내 정보 오른쪽 위 톱니바퀴로 열기. 개인정보 고치기 포함 |

# 기획서 반영 현황

기획서의 각 항목이 프로토타입에서 어떻게 구현되었는지 정리한 표입니다.
✅ 구현 · 🟡 연출(프로토타입에서는 흉내만 냄) · ⬜ 미구현

## 1. 앱 주요 기능

| 기획 항목 | 상태 | 구현 내용 / 위치 |
| --- | --- | --- |
| 지도: 남한 지도 중심 메인 화면 | ✅ | `MapScreen`, `KoreaMap` (남한 행정구역 SVG) |

| 지도 조작: 확대/축소, 현재 위치로 이동 | ✅ | 우측 하단 버튼, 드래그·핀치·휠 |

| 이야기책: 주제별 묶음, 해금 시 표시, 진행률 | ✅ | `StoryBookScreen`, `storyBooks.ts` |
| 미해금 내용 '아직 발견하지 않은 이야기' | ✅ | |
| 이야기책 키워드 검색 | ✅ | |
| 학습: 전체 화면 소개 글 + 사진 | ✅ | `LearnScreen`, `contents.ts` |
| 학습: 영상 | ✅ / 🟡 | 장소별 3D 배경에서 역사 인물과 내 캐릭터가 대화, 배경 음악. 목소리는 녹음 파일(public/audio/장소id/줄번호.mp3)이 있으면 먼저 재생, 없으면 기기 한국어 목소리 중 인물에 맞는 남성/여성으로 읽음. 전체 화면(지원 안 되는 기기는 화면 덮개 방식) `HistoryScene` |
| 최초 사용 시 얼굴 등록 → 사진/영상에 반영 | ✅ | 온보딩에서 "카메라로 찍기 / 앨범에서 고르기" 선택 (휴대폰: 앞면 카메라·사진 앨범, 컴퓨터: 웹캠 화면 촬영, 웹캠이 없거나 권한 거절 시 앨범 안내) → 만화풍 변환 → 학습 영상 장면 속 내 캐릭터 얼굴에만 반영 (기기에만 저장) |
| 학습 단계 쉬움/보통/어려움, 기본 보통 | ✅ | 화면 오른쪽 상단, 설정에서 기본값 변경 |
| 하단 '학습 완료' / '퀴즈 풀어보기' | ✅ | |
| 학습 아카이브: 학습 완료·퀴즈 완료 표시 | ✅ | `ArchiveScreen` (실제 기록 기반) |
| 아카이브 연/월 선택 | ✅ | |
| 퀴즈: 학습 내용 기반, 매번 다른 문제 | ✅ | AI 출제(Vercel + Claude API) 또는 사실 묶음 기반 자동 생성 |
| 퀴즈 난이도 = 학습 글 난이도 | ✅ | 난이도별 퀴즈 3문제씩 (`quizBank.ts`) |
| 메뉴의 복습 퀴즈 (틀린 문제 중심) | ✅ | 틀린 문제 자동 저장 → 우선 출제 → 맞히면 제거 |
| 로그인: 간편(네이버·카카오·구글) / 이메일 | 🟡 | 화면과 흐름만 구현, 실제 인증 없음. 간편 로그인은 각 회사 공식 원형 아이콘 이미지 사용 |
| 이메일 기억하기 | ✅ | 기기에 저장 |
| 회원가입 | 🟡 | 화면과 흐름만 구현 (서버 없음). 이메일·비밀번호(8자 이상)·비밀번호 확인 입력 즉시 안내, 필수 약관 동의(예시 문구 + 초등학생용 '쉽게 읽는 요약'), 태어난 해·달로 만 나이를 계산해 만 14세 미만이면 보호자 허락 단계 추가 → 완료 후 닉네임을 채운 온보딩. 간편 로그인 첫 이용도 같은 단계를 거침. 비밀번호·생년월·보호자 이메일은 저장하지 않음 `SignupScreen` |
| 비밀번호 찾기 | 🟡 | 화면과 흐름만 구현 (메일 발송 없음). 이메일 입력 → 재설정 링크 안내 → 로그인으로 `ResetPasswordScreen` |
| 먼저 둘러보기 → 기기 저장 → 로그인 시 계정으로 | ✅ / 🟡 | localStorage 저장, 로그인 시 안내 메시지 |
| 푸시 알림: 근처 장소 도착 시 (500m) | 🟡 | 지도 상단 알림 배너로 연출, 반경 값은 `NEARBY_RADIUS_M` |
| 푸시 알림 ON/OFF, 기본 ON | ✅ | 설정 |
| 아바타: 처음 이용 시 성별/체형 등 외형 설정 | 🟡 | 성별, 머리 모양 선택 (남: 짧은 머리·상투, 여: 땋은 머리·단발·장발 그림). 체형·피부색은 그림이 추가되면 다시 선택 가능 (`OnboardingScreen`의 `SHOW_DETAILED_LOOK`) |
| 역사 인물의 장비·무기·의복 수집 | ✅ | 장소 학습 완료 시 획득 (`avatar.ts`) |
| 아이템마다 능력치 | ✅ | 공격·방어·지혜. 전투력 = 착용 아이템 능력치 합 + 레벨(1 + 학습한 장소 수) × 60, 모든 화면이 같은 계산(`powerOf`). 아바타 탭 ⓘ에서 올리는 방법과 계산 내역 안내 |
| 획득/미획득 아이템 확인 | ✅ | 미획득은 자물쇠 + 획득 방법 안내. 지도 장소 카드·학습 화면에 "이곳에서 얻는 아이템"과 획득 완료 표시 |
| 아이템 착용 (옷 입히기) | ✅ / 🟡 | 머리·손·몸 부위별 착용/해제, 능력치 반영. 머리(갓·투구)·손(활·검·붓·태극기·독립선언서) 아이템은 캐릭터 그림 5종마다 맞춘 자리에 직접 입힘. 옷(관복·화랑 예복·갑옷)은 그림이 없어 아직 원형 배지 `CharacterAvatar` |
| 친구에게 도전장 링크 보내기 | ✅ / 🟡 | 서버 없이 링크(# 뒤)에 닉네임·성별·머리 모양·착용 아이템·레벨만 담음 (얼굴 사진 제외). 휴대폰은 공유하기, 컴퓨터는 링크 복사. 받은 사람은 도착 화면 → 같은 턴제 대결(상대 전투력은 링크의 아이템·레벨로 다시 계산), 아바타가 없으면 바로 대결 후 시작하기 안내, 결과 후 답장 도전장. 이상한 링크는 "도전장을 읽을 수 없어요". 실시간 대결은 아님 `ChallengeScreen`, `lib/challenge.ts` |
| 친구와 경쟁: 무작위 문제, 맞히면 공격/방어 선택, 턴제 | ✅ | 상대 공격력은 아이템·레벨 기반. 승패 모션(승리: 점프·꽃가루, 패배: 주저앉기), 다시 도전, 대결 기록(승·패·승률·최근 5판)을 경쟁 화면과 내 정보에 표시 `BattleScreen` |
| 이야기책: 책 모양, 전체 권 수 표시 | ✅ | 책장 UI, ‘발견 / 전체 권’ + 진행 바 |
| 내 정보: 획득한 배지, 관심 장소 | ✅ | 배지 9종 자동 획득, 하트로 관심 장소 등록 |
| 닉네임 바꾸기 | ✅ | 내 정보(연필 아이콘)·설정(계정 칸)에서 바텀시트로 변경. 앞뒤 공백 제거 후 1~10자, 글자 수 표시, 모든 화면에 바로 반영 `NicknameSheet` |

## 2. 화면 및 요소 배치

| 기획 항목 | 상태 |
| --- | --- |
| 홈: 지도 옵션(발자국 ON/OFF, 학습 가능 지역 ON/OFF) | ✅ |
| 학습 가능 지역 반투명 초록색 영역 | ✅ |
| 메뉴: 왼쪽 상단 (학습 아카이브, 설정, 퀴즈, 복습 퀴즈) | ✅ |
| 메뉴: 도움말 (앱 사용법 7가지 + 자주 묻는 질문 3가지, 누르면 펼쳐지는 방식) | ✅ |
| 도움말: 문의하기 (종류·제목·내용 → 내 문의 내역, 답변 대기 중/답변 완료) | 🟡 | 화면과 흐름만 구현. 문의는 기기에만 저장하고, 운영팀 답변은 시연용 예시 1건. 실제 서비스에서는 서버 저장·관리자 답변 필요 |
| 하단 바: 지도 / 이야기책 / 아바타 / 내 정보 | ✅ |
| 컴퓨터 화면에서 보기 | ✅ | 휴대폰 모양 틀(393×852)을 가운데에 두고, 화면 세로가 짧으면 틀을 통째로 비율 그대로 줄여 하단 바까지 항상 보이게 함 (바텀시트·토스트·영상 장면 전체 화면도 틀 기준). 휴대폰은 화면을 꽉 채움 `lib/frameScale.ts` |
| 설정: 기본 학습 단계, 로그아웃(비로그인 시 로그인), 푸시 알림 | ✅ |

## 실제 서비스로 만들 때 필요한 것

GPS 위치 연동, 소셜 로그인과 서버 저장, 전문 일러스트 캐릭터, 성우 음성 또는 고품질 TTS, AI 이미지/영상 생성(얼굴 합성)

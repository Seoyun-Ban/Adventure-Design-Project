# 학습 내용 참고 자료

## 원칙

- 학습 내용은 공인된 자료를 바탕으로 작성·검증했습니다.
- 인물 대사는 교육용 상상 대화입니다. 앱의 영상 장면에도 '역사 인물 상상 대화'라고 표시합니다.
- 자료마다 연도·숫자가 다른 내용은 학습 글과 퀴즈에서 단정하지 않거나 묻지 않습니다.
